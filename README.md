# VULCANO

Videojuego educativo en MakeCode Arcade sobre supervivencia en la Luna y Marte.
Proyecto del equipo VULCANO, Institución Educativa Julio Pérez Ferrero, para el NASA Space Apps Challenge 2026 (reto "Build a Junior Astronaut Mission Trainer").

Página del proyecto: https://deysirolon-sys.github.io/vulcano/
